# Bukti eksperimen - OTA Blynk

Belum ada bukti eksperimen fisik di folder ini. Tambahkan foto atau screenshot asli dengan nama yang jelas, misalnya `01-kondisi-awal.png`.

- [ ] Versi 1.0.0 pada perangkat sebelum update.
- [ ] Shipping Blynk.Air dengan target perangkat uji.
- [ ] Status shipping dan versi 1.0.1 sesudah reconnect.
- [ ] Hasil uji kendali setelah reboot; jangan tampilkan token/password.

Setelah berkas ditambahkan, sisipkan ke LAPORAN.md menggunakan pola berikut (ganti nama sesuai berkas nyata):

```markdown
![Kondisi eksperimen](bukti/01-kondisi-awal.png)

Gambar X. Kondisi, setpoint, tanggal, dan penjelasan singkat pengamatan.
```

Diagram pada folder `gambar/` adalah ilustrasi rancangan, bukan bukti bahwa alat telah diuji.
